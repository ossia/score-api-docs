◆ colorConversion

QString score::gfx::interop::VideoOutputStrategyConfig::colorConversion

The RGB->wire colour conversion the encoder must use, from DirectVideoOutputBackend::colorConversion(). A GPU-direct strategy builds its own encoder, so without this it has no way to learn the backend's colour decision and has to invent one – which is how AJA ended up emitting SDR BT.709 on the RDMA path while the host-staged path honoured HDR10, on the same device and the same setting. Empty means "not supplied"; a strategy may then fall back, but should not have to.

◆ frameByteSize

std::uint32_t score::gfx::interop::VideoOutputStrategyConfig::frameByteSize {}

Frame size in vendor pixel format bytes (already accounts for row stride padding, e.g. v210 line layout). Strategies allocate the buffer ring at this byte size and the vendor pin callback receives it directly.
