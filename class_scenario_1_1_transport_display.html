Detailed Description

The transport's position readout.

In musical mode: bar, pulse and quarter of pulse, the time underneath in smaller digits, and a grid with one cell per pulse of the current bar. Otherwise the time alone.

The widget has the same size in both modes, so that toggling the mode does not move the rest of the toolbar.
