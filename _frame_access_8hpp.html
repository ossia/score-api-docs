Detailed Description

Classifies a stream by what reaching an arbitrary frame costs.

Scrubbing to a frame means decoding from the keyframe before it, so the longest run of non-keyframes bounds the cost of any seek, on every machine.

AV_CODEC_PROP_INTRA_ONLY is not set for CineForm, PNG, FFV1 or all-intra H.264 / HEVC / MPEG-2 (AVC-Intra, XAVC-I, IMX), so the stream itself is read: a container index covering every frame (MP4, MOV) when there is one, else the keyframe flags of the first demuxed packets. Matroska indexes only some keyframes; MPEG-TS and MXF have no index.
