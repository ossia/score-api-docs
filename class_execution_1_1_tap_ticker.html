Detailed Description

Taps are driven by no time process: this gives them a token at the start of each tick, so that the graph runs them after their sources.

The list of nodes is built on the GUI thread and published whole; the execution thread only reads it. A replaced list is freed once the execution thread cannot be reading it anymore. A node that is not in the running graph keeps the one token it was given.
