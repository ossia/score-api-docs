Detailed Description

GPU-side buffer format conversion (scatter).

Converts vertex attribute data between formats on the GPU using a compute shader. The typical use case is widening float3→float4 when uploading CPU mesh data into SSBOs for compute shader consumption.

The raw CPU data is uploaded as-is into a staging SSBO (bulk memcpy, no per-element processing). A small compute dispatch then reads from the staging buffer and writes to the destination SSBO with proper format conversion and default component values (GPU convention: x=0,y=0,z=0,w=1).

Usage:

  1. Call init() once per QRhi lifetime.
  2. In the update phase: upload raw CPU data to staging, call updateParams().
  3. In the render phase: call dispatch() inside a compute pass.
