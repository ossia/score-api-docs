Detailed Description

The output that renders, for the editor's previews, the nodes no output of the patch renders.

Each preview of such a node takes one of its inputs. The node renders into a target of the size the preview asks, and the preview's tap reads it back in this output's render list, as it would in a list of the patch. All of them share this one render list and device: a chain several previews show renders once.

◆ currentRenderTarget()

TextureRenderTarget score::gfx::PreviewHubNode::currentRenderTarget ( ) const
overridevirtualnoexcept

The output's current backing render target + render-pass descriptor, as the upstream nodes should render into it NOW.

A sink whose render target / render-pass descriptor can be recreated mid-session (e.g. an offscreen BackgroundNode on a viewport resize, which deleteLater()s the old target and installs a fresh one) must override this so that a renderer which cached the target by value at construction can re-adopt the live handles when it is rebuilt (RenderList::maybeRebuild or rebuildOutputTargets -> OutputNodeRenderer::init). The default returns an empty target, meaning "nothing to refresh — keep the value captured at createRenderer() time".

Without this, the resize fast-path (resizeSwapchainSizedTargets, which re-inits the output renderer in place instead of reconstructing it) leaves the upstream node's final pass bound to the freed render-pass descriptor — a Vulkan use-after-free of the VkRenderPass.
