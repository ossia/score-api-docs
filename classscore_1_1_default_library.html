Detailed Description

Whether the default library package is installed, and up to date.

The default library is the package installed in <library>/packages/default: it holds the templates, and the presets and media that many examples use. Its installed version comes from its package.json.

The package manager lives in a plug-in: it tells this object which version is available online once it has fetched the package list, gives it the function that installs that version, and reports the progress of every install of the package, wherever it was started from. The start screen shows the state and calls install().
