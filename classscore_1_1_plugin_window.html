◆ editorPixelRatio()

double score::PluginWindow::editorPixelRatio ( const QWidget &  w)
static

How many of an editor's own pixels make one of Qt's logical pixels, on the screen of w. Win32 and X11 editors count physical pixels: this is the device pixel ratio. Cocoa editors count points, which are Qt's logical pixels unless Qt scales those itself (QT_SCALE_FACTOR, QT_SCREEN_SCALE_FACTORS): this is then that scaling alone, whatever the backing scale of the screen.
