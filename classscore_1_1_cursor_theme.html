Detailed Description

Builds the cursors and puts them everywhere a standard shape would reach the platform: widgets, windows (QML included), the override cursor and the cursors of drag and drop.

A set of cursors is built for each scale of screen something is shown on, when first needed: the platforms show a window's cursor at the scale of the window's screen (one scale for the whole desktop on X11), and Qt resamples a pixmap made for another one. Each widget and window gets the set of its screen, again when it moves to another screen; the override cursor and the cursors of a drag get the set of the screen under the pointer.
