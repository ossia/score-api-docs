Detailed Description

The skin editor, inlined as a settings sub-tab.

Writes straight into score::Skin and emits changed(), so the UI updates as you edit. Fonts are per-role: a global size cannot coexist with per-skin fonts, since the skin's "fonts" block is applied over it and wins.
