Gfx::pointer_addresses Struct Reference

Detailed Description

The pointer addresses the window devices publish next to cursor/scaled, cursor/gl and cursor/absolute (Window/WindowDevice.hpp, Window/OffscreenDevice.hpp):

  • cursor/clip: the mouse in clip space, x and y in [-1, 1], y up: the mouse of vertexshaderart (greggman/vertexshaderart src/js/main.js recordMouseMove, x * 2 - 1, y * -2 + 1).
  • touch/points: the pointers, a list of 32 [x, y, pressure] in the same space. Slot 0 is the mouse or the first finger, then one slot per finger in the order they came down; a released slot keeps its position, its pressure drops to 0 (main.js addTouchPosition / addTouchPressure / getTouchIndex). Writable: anything that writes it moves the pointers.
  • touch/history: a texture, vertexshaderart's touch – the last 240 frames of touch/points, 32x240 (score::gfx::TouchHistoryNode).

A shader input named mouse or touch is bound to these by default (ISFProcess.hpp), as any other address, and can be rebound or cabled.
