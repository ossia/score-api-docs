Detailed Description

Named toggles in rows, one per label. A click toggles a cell and a drag paints the same state over the others; the context menu sets all, none, inverts, and edits the set as text: the labels of the cells that are on, separated by commas.

The value is an ossia list of booleans, one per label, in their order.
