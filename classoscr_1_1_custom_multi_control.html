Detailed Description

template<typename Item>
class oscr::CustomMultiControl< Item >

halp::custom_multi_control. Values are normalized; a gesture is one undo step.

Or, when the item's values is a std::tuple, each value is the control's own (a list, a 2D point...), kept up to date, and edited through transactions, a tuple of halp::transaction, one per control. It may be shorter: the controls past its end are only shown.
