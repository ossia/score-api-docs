Ui::Monitor::Buffer Namespace Reference

Detailed Description

Reading the elements of a raw buffer as floats: what the bytes are, how many components an element has, and where the elements are. Nothing of this travels with a GPU buffer, the user says it.

The gather pass of the buffer view: a compute shader copies the elements a view reads, wherever they are in the buffer, one after the other into a staging buffer, and that alone is read back. What it reads back is the size of the elements, not of the bytes between them.

In an overview it also measures every element of the window: the extent of each component and how many are not finite, at the head of the staging buffer.

This holds what the CPU computes for it, and the same arithmetic as the shader, which the tests check it against.
