The values the parameters last had, sent to the plug-in through clap.params.flush rather than process(): process() requires the plug-in's declared audio port layout (a plug-in may assert on it, e.g. Floe). clap/ext/params.h: flush is [active ? audio-thread : main-thread], and this is the audio thread, not within process(). With inputs_only, only those of the parameters whose input carries a value in this block, and those changed marks.
