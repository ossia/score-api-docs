Detailed Description

Lists, decodes and watches the folder of a sound_set port, and publishes the result to the processor.

Lives on the UI thread. Listing and decoding run on score::TaskPool. Each new snapshot reaches the processor through publish, which swaps it in between two ticks and flags the previous one as superseded. A superseded snapshot is freed here, on the UI thread, once nothing pins the sounds only it holds. The audio thread never frees nor drops a reference to anything.
