Nodes::Looper::value_slot Class Reference

Detailed Description

Where the value looper keeps a value: every one it records, holds or sends is copied, moved and let go of through this type and nowhere else.

A value is kept as a plain ossia::value. Numbers, booleans, impulses and vectors live inside it, so that keeping, copying and dropping them never allocates; a string, a list or a map owns heap memory, which is allocated when it is copied in and freed when it is let go of, on whatever thread does it, the audio thread included. A pooled allocator for those is a change of this type alone.
