Ui::Monitor Namespace Reference

Detailed Description

Speaker layouts: the name and position of each channel, for labels, the surround views, and loudness channel weighting (ITU-R BS.1770).

What the views of monitoring processes share: reading their settings from the model, and showing the inlet they draw.

MIDI messages as the monitoring views name them: note names, what a status byte is, and one line of text per message.

What every monitor draws with: the same background, grid, text and colour maps, so that meters, scopes and spectra read as one family.

Power spectra calibrated in dBFS: a full-scale sine reads 0 dB at its frequency whatever the FFT size and window, and a band sums the energy of its bins so that broadband noise reads its true band level.

How the views of textures show one that holds several images, a 3D texture, an array or a cube map: the controls that pick it, and what the node tells the views of the texture it got.
