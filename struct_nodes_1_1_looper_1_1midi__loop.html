Detailed Description

The notes and controllers of a MIDI loop, in fixed storage.

The passes are a pass_stack; every event is tagged with the pass that recorded it: undoing a pass hides its events, redoing shows them again, erasing it removes them. Controllers of a pass replace the same controller of earlier passes where the pass went, so two curves of one controller never fight; notes do as well with OverdubMode::Replace. Each event keeps every pass that replaces it, and is heard when none of them is: muting, erasing or merging a pass leaves what the others replace as it is.
