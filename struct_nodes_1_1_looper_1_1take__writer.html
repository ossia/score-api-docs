Nodes::Looper::take_writer Struct Reference

Detailed Description

Where a looper's takes go, and the names they get.

A saved document keeps them next to it, in a "Takes" folder, which goes along with the document when it is copied. An unsaved one keeps them in the application's data folder, in a folder of its own; nothing deletes them there, so a crash loses nothing.

Every take gets a name of its own: a sound file is cached by its path, and a take written over an earlier one would play the earlier one's audio.
