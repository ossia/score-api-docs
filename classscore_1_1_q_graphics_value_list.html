Detailed Description

A list of elements edited in place: each element is a row of spinboxes (or combo boxes for columns with choices). "+" appends a copy of the last row, "x" removes a row, the context menu inserts, duplicates, moves and clears, and "Edit as text" takes the whole list as text ("4 7 10", or rows separated by commas: "4 100, 7 80").

Lists of single numbers flow in lines of itemsPerLine() cells; lists of several columns show one row per element under the column names.

The value is an ossia list: of numbers for one column, of lists otherwise.
