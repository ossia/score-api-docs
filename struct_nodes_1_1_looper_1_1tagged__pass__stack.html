Detailed Description

template<typename Store, typename Pass, int MaxLayers>
struct Nodes::Looper::tagged_pass_stack< Store, Pass, MaxLayers >

A pass_stack whose material is all kept apart and tagged as tagged_material says: the hooks that move it along with its passes, the merging of two passes, and where the pass being taken in went. Store gives, besides the pass_stack hooks it wants to do more in:

template <typename F> void for_each_material(F&& f); // every piece template <typename F> void remove_material(F&& gone); // those gone says void clear_material(); // every pass is gone void pass_state_begun(); // a pass starts: what it touched is forgotten

Merges pass at and the one over it into one, heard as the two were. A muted pass merged with one that is not is left out of the merged one: merging is where it is lost. With undoable, undo takes the upper pass out again, as long as nothing else changes the passes.
