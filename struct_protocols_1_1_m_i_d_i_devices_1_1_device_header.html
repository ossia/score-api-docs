Protocols::MIDIDevices::DeviceHeader Struct Reference

Detailed Description

A document's own fields, without its controls: what a library listing needs.

Kept separate because the controls are the bulk of a file – an instrument's patch names run to hundreds of kilobytes – and listing a library must not read them.
