◆ install()

void score::OnlineExamples::install ( const OnlineExample &  ex,
std::function< void(QString)>  done,
bool  replace = false 
)

Calls done with the local path, or an empty string on failure. An installed example is downloaded again only when replace is set; the local copy is then replaced whole, files the new version does not have included, and only once the new version is completely written: on any failure the local copy stays as it was. A request for an example already being downloaded waits for that download.
