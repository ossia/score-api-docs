Detailed Description

The waveform of a sound file, for a widget that draws it: the audio file manager decodes the file, a WaveformComputer renders it into images, and paint() draws them.

Images are requested once the file is decoded, and again whenever the size, pixel ratio or range change. They come back asynchronously: updated() tells the owner to repaint.
