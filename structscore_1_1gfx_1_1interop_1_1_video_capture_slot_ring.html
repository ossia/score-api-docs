Detailed Description

Lock-free SPSC handoff between the capture thread and the renderer. Capture thread bumps latestFrameId and publishes the slot index; renderer polls and consumes.

producer: writeIdx = (writeIdx + 1) % N; ingest into slotBuffer(writeIdx); latestSlot.store(writeIdx, release); latestFrameId.store(++currentFrame, release); consumer: id = latestFrameId.load(acquire); if (id == lastIngested) skip; slot = latestSlot.load(acquire); ingest from slot; lastIngested = id;
