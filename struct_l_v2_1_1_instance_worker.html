LV2::InstanceWorker Struct Reference

Detailed Description

The worker:schedule feature of one instance, and the two queues between the threads that run the instance and the worker thread: requests one way, answers the other. Both are allocated with the instance, a fixed number of packets each; when one is full, schedule_work or respond answer LV2_WORKER_ERR_NO_SPACE.
