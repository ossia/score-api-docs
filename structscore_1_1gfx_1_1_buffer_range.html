score::gfx::BufferRange Struct Reference

Detailed Description

The byte range a buffer published at offset / size is bound with (shader board U42): that range, including, for a storage block, one that starts at 0 and stops short of the end (so its .length() is the published count; a uniform block keeps the whole buffer there). An offset off the device's alignment (bufferOffsetAlignment) is refused by blockRefusal before a buffer is adopted; here it binds the whole buffer from byte 0 with one warning naming who, as a safety net. size 0 = to the end.
