Detailed Description

An undoable edit performed by a script.

A script can change state the engine knows nothing about - the QML side of an application, an external socket. This command lets such edits take part in undo, together with the engine edits around them.

The command carries a handler name and the payload for each direction, rather than the two closures the interface suggests: a command is serialized, both for the crash-recovery backup and for the network plug-in, and a QJSValue cannot be. Handlers are registered by name with Score.registerCommandHandler().

A handler that is not registered when the command runs - a backup restored before the script that owns it has loaded - is reported once and skipped.
