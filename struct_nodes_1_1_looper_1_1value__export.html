Nodes::Looper::value_export Struct Reference

Detailed Description

A value take: what is heard of a value loop, or of one of its passes, as a small JSON file, which the Automation process reads back.

{ "format": "score-value-take", "version": 1, "rate": 48000, // frames a second "frames": 96000, // the loop's length "tempo": 120, // what it was played at, and in "meter": [4, 4], "components": 1, // what an automation can play of it: the // most numbers a value has, or 0 when the // values are not all numbers, vectors and // lists of numbers, or have more than // max_components "min": [0.1], "max": [0.9], // of each component, when there are "events": [ [0, "float", 0.25], // [frame, type, value], by frame: a value [12000, "impulse"], // held until the next one, an impulse [24000, "vec3f", [1, 2, 3]], // fired on its frame [36000, "list", [["int", 1], ["string", "a"]]], [48000, "map", {"x": ["bool", true]}] ] }

The types are those of ossia: impulse, int, float, bool, string, vec2f, vec3f, vec4f, list, map; a list or a map holds [type, value] pairs. The first value holds from the loop's start when it is on frame 0, else the last one holds there, the loop going round.
