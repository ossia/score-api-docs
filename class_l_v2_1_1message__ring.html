LV2::message_ring Class Reference

Detailed Description

Messages of any size from one thread to another, neither of which allocates nor frees once the ring is built: a message is a header (its port, protocol and size) followed by its bytes, laid over consecutive packets, as jalv lays a size-prefixed message in its zix ring.
