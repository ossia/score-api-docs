Nodes::Looper::loop_input Struct Reference

Detailed Description

What came in on Mode, and what it shows.

A value that comes in on every tick, as an automation's or a cable's does, asks for its mode once, when it changes: the looper changing Mode by itself, at a recording's end or on a full buffer, does not make the cable ask again and the mode flip back. A value that is what is asked for already asks nothing, so that the looper's own change of Mode, coming back from the UI, is not taken for a request, nor clears what is queued.
