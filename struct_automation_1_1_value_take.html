Automation::ValueTake Struct Reference

Detailed Description

A value take of the value looper, as an automation can play it: one curve of steps for each number of its values. The file format is described with Nodes::Looper::value_export.

The curve of component, its values from 0 to 1 between min and max: each value held to the next, the last one from the take's start up to the first when it does not start there. The take spans span of the curve, which holds its last value after it and is cut at 1.

◆ components

int Automation::ValueTake::components {}

Numbers of each value: 1 for numbers, n for vectors of n, the most a list has for lists. A value that has fewer leaves the others where they were; before a number first comes, its first value holds.
