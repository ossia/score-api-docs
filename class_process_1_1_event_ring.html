Process::EventRing< T, N > Class Template Reference

Detailed Description

template<typename T, std::size_t N>
class Process::EventRing< T, N >

Discrete events from the execution thread to the GUI, none lost while they fit: a bounded single-producer queue, which does not allocate when pushing. A full queue drops what is pushed and counts it, so that the view can say so.

Every view refreshed in the same tick of the monitor clock gets the same events (see monitorFrame()); outside of a tick, drain() takes them.

T is copied in and out; keep it small and trivially copyable.
