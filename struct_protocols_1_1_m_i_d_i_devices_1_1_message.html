◆ channels

std::vector<int> Protocols::MIDIDevices::Message::channels

1-16. Empty means "whichever channel the device is set to"; several means the source states the same control on each of them, which an instrument's name set routinely does ("every channel but 10").

◆ number

int Protocols::MIDIDevices::Message::number {-1}

CC number, note number, or the NRPN/RPN parameter MSB. -1 when the message addresses nothing, as pitch bend, aftertouch and program change do not.
