Detailed Description

Ties a view to the monitor of the process it shows.

While the view is visible in a graphics view it counts as one of the monitor's viewers, and refresh is called with the monitor at the display rate (see MonitorLink::setRefreshInterval). attached is called whenever the process starts or stops running, with the new monitor or null.

All the links of the application share one timer, at the UI event rate of the settings, which only runs while some link has a monitor: while a monitoring process runs, with execution updates enabled. All the links of one monitor are refreshed in the same tick, in which the monitor's EventRing and LatestValue give each of them the same content.
