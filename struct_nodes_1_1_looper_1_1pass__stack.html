Detailed Description

template<typename Store, typename Pass, int MaxLayers>
struct Nodes::Looper::pass_stack< Store, Pass, MaxLayers >

The passes of a loop, one over the other, whatever they hold.

A pass is the first recording or an overdub on top of it. Undo hides the newest one and redo shows it again; erase takes one out for good; mute keeps one but does not hear it; a pass past Max layers is merged with another, or takes the place of one, which is set aside for undo to put back. The stack does the bookkeeping of all of it, the same for every looper: which passes are heard and which redo brings back, the length each one repeats with, the length of the loop before and after each one, which ones are muted, the layer set aside and the merge undo can take apart.

Pass holds, besides what the looper keeps of its own for a pass (a buffer, a gain...), period, loop_before, loop_after and muted, and is copied whole as the passes move. What a pass recorded may instead be kept apart, each piece tagged with the index of its pass and with the passes that replace it, e.g. MIDI events: Store moves those along as the passes move, through these hooks, which tagged_material below implements for any such piece:
