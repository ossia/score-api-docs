oscr::CustomItemWaveforms Class Reference

Detailed Description

The sound files a custom item draws with its painter's draw_waveform(), see halp::waveform_view: score's waveform renderer draws them. Each view of the item gets its renderer the first time it is drawn; an item that draws none costs nothing.
