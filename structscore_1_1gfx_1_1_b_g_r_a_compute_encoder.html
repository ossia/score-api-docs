Detailed Description

Compute-shader RGBA -> BGRA (NTV2_FBF_ARGB byte order) encoder targeting an external SSBO.

One thread per pixel. Reads RGBA, writes one little-endian 32-bit word with bytes (B, G, R, A) in memory order - i.e. AJA's NTV2_FBF_ARGB layout. No colour matrix, no chroma subsampling: this is a passthrough with byte swizzle.
