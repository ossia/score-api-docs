Detailed Description

GPU RGBA->UYVY encoder (packed 4:2:2).

Output: RGBA8 texture at half width. Each output texel encodes 2 source pixels as (U, Y0, V, Y1). Single render pass, single readback.

The readback data is directly in UYVY memory layout, ready for GStreamer video/x-raw,format=UYVY.
