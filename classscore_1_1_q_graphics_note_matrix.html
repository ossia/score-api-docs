Detailed Description

Where each degree of an octave goes: one column per input degree, one row per output degree from the root (bottom) to the octave above (top). A column has one lit cell, or none when that degree is muted.

A click lights a cell, a click on the lit cell mutes the column, a drag moves the lit cell up and down. The context menu resets, inverts and edits the map as text.

The value is an ossia list of 12 integers, -1 for a muted degree.
