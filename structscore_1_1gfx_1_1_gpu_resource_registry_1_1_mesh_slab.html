Detailed Description

Slab handle returned by MeshArenaManager::acquire.

One per mesh (keyed on stable_id). Holds ONE vertex-unit allocation (shared across every vertex stream) and ONE index-unit allocation. Per-stream byte offsets are derived in meshSlabOffsetBytes() as vertex_slot.offset * stride / index_slot.offset * 4. This guarantees baseVertex consistency across all vertex bindings even after fragmentation — see the indirect-draw invariant above.

last_seen_frame is bumped each frame the owner calls markSeen(); sweep() frees slabs whose last_seen is older than current_frame - grace. Grace = FramesInFlight + 1 is the safe default (let in-flight draws finish).
