Process::PresetTree Struct Reference

Detailed Description

The presets of a process, in folders by category, as the library shows them and the preset button's Forward / Back walk them: in each folder its presets, then its subfolders, each by name; the process's own presets (a plug-in's) last, in a "Built-in" folder.
