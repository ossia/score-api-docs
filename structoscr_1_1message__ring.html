Detailed Description

template<typename T, std::size_t N = 16>
struct oscr::message_ring< T, N >

Processor to UI messages too large to travel inside an execution command: a fixed ring with one writing thread (the processor's) and one reading thread (the UI). Nothing allocates once it is built; the reader moves the messages out, so what they own is freed on the UI thread.

When the ring is full, push() drops the message and returns false: the UI misses that update and catches up with the next message that fits.
