Nodes::Looper::erase_request Struct Reference

Detailed Description

Sent by the view to the looper: erase pass pass, counting from the oldest one, of a loop the view showed with layers passes, or mute it or unmute it when mute is set. A loop that has changed since is left alone. With take set, it asks instead for a take of the loop as it is heard now, the pass being taken in included as far as it went: take numbers the request, which view_message::answered gives back once it is written. With last set as well, the take is only the files of passes pass to last of the layers the view showed, given back as the message's part.
