Detailed Description

The window shown when score starts without a document.

Layout:

+------------------------------------------------------------—+ | splash artwork: logo, tagline, version [update notice] × | +--------—+------------------------------------------------—+ | Home | | | Examples | page (home / examples / learn / community) | | Learn | | | Community | | | Exit | | +--------—+------------------------------------------------—+

Every way of leaving the screen without choosing anything (Escape, the × button, a close request) opens a new empty score, so the user always ends up in a usable editor.

Templates, examples and recent files are plain .score files; their project information (name, author, thumbnail) is read in the background with ProjectInfo::peek() and shown on hover or on the example cards. Lays out fixed-size cards left to right, wrapping to as many columns as the width allows.
