Ui::BufferView Namespace Reference

Detailed Description

Shows what a GPU buffer holds: its elements as curves, a table, an image or histograms. The bytes say nothing of what they are: the element type, the components, the stride and the offset are the user's.

While a view shows it, the node reads the buffer back at most at the rate the views refresh at, and decodes it into floats on the render thread. A compute pass first gathers the elements read into a buffer of their own, so that a readback holds them and nothing between them, at most 16 MiB; without compute shaders or for a buffer that is not a storage buffer, the range from the first to the last element is read, cut to 16 MiB.
