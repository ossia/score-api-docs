Detailed Description

The draw-count rung, emulated with compute for backends without it.

A producer that writes its draw count on the GPU may leave anything in the command slots past that count: syn-pop-draw writes poison commands there. The count rung (drawIndexedIndirectCount) never reads them, but it is not always there: Metal implements it with indirect command buffers, which a pipeline that binds textures cannot use, and some drivers lack it outright. The full-capacity multi-draw rung would then draw the dead slots.

run() copies the commands to a buffer of its own with every slot at or past the count zeroed, so a multi-draw of the copy paints what the count draw would. Nothing is read back. It needs compute and a storage-usable command and count buffer, and returns nullptr otherwise.

Call it outside a pass, before the render pass that draws.
