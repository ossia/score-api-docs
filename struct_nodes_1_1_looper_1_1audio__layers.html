Detailed Description

The audio of every pass of a loop, in buffers reserved before playback. The passes are a pass_stack; this is what the audio of each is.

slots buffers hold the passes, each capacity frames long for each channel, and spare_slots more are kept for merging: past slots passes, two layers are merged into a spare buffer a part per tick: the two oldest while the overdub that asked for room goes into the other one, or the newest and a pass that just ended over it. The memory is reserved without being written, so only what is recorded into is actually used. It is shared, so that a take of it written once the looper is gone still reads it.

)
inlinenoexcept

Starts an overdub pass at position start. With slots passes kept and oldest set, the two oldest start merging into one, so the oldest undo is lost; the new pass is heard at once, the merge going on in the following ticks. Without, the pass is one more, merged into the newest once it ends. replace, a pass heard, makes room for it instead: it is set aside, undo putting it back.
