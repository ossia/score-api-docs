mtk::midi_clock Namespace Reference

Detailed Description

Time-dependent logic of MIDI Sync Out, free of any clock source and of any output: every function takes the current time as an argument, so that it can be driven by std::chrono::steady_clock in the sending thread and by a fake clock in tests.
