Process::MidiSysexArena Class Reference

Detailed Description

Whole system-exclusive messages for a plug-in host to hand a plug-in.

A MIDI port carries a system-exclusive message as the SysEx7 packets it is made of. A VST, VST3 or CLAP plug-in takes it as one event that points at the whole F0 ... F7 message, and may read it until its process call returns. feed() joins the packets of one input port (one stream per port, which keeps a message whose packets span two ticks) and copies each whole message into storage the node owns: nothing is allocated on the audio thread. The host calls clear() once per process call, before it makes the events of the next one.

Between two clear(), up to capacity bytes of messages are held, each of up to max_message bytes, F0 and F7 included. A message past either limit is not delivered and dropped() counts it.
