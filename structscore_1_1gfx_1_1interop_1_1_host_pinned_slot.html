score::gfx::interop::HostPinnedSlot Struct Reference

Detailed Description

One slot of the ring. The host buffer is page-locked (4 KiB aligned, allocated via nv_dvp_aligned_alloc). Backends may attach additional per-slot resources (DVP buffer handle, GL buffer id, etc) which live in the opaque pointer below.
