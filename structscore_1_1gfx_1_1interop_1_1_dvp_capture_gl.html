Detailed Description

template<class Lock>
struct score::gfx::interop::DvpCaptureGl< Lock >

OpenGL capture strategy via NVIDIA "GPUDirect for Video" (DVP).

Vendor-neutral: the per-vendor part is the Lock policy (how the sysmem slot is page-locked for the card's DMA engine) plus the dvpFormat (the 4-byte texel layout of the decode-input texture). The capture loop writes each frame into slotBuffer(i) (card DMA for AJA, CPU memcpy for DeckLink); ingestFrame(i) then DVP-copies the slot to the output texture.

The QRhi GL context must be current on the calling thread when init() runs and when the renderer-side acquire/release runs.
