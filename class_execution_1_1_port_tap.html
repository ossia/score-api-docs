Execution::PortTap Class Reference

Detailed Description

Watches a port of a running process: what an outlet produces, or what an inlet receives, its cables and its address merged as the process gets them. While it exists, a node of the execution graph gets the same edges as the port and copies what arrives into the monitor; it goes away with the tap. Nothing is changed in the document, and the port does what it does without a tap: an outlet whose only edge is the tap's still writes to its address.

A tap belongs to the execution it was made in: once that execution is stopped or reloaded, monitor() is null and the tap only waits to be destroyed.
