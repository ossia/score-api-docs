Nodes::Looper::held_timeline Struct Reference

Detailed Description

What is heard of the held values of a key round a loop: the positions where it changes, in order, and the value of the loop that holds from each one until the next, the last holding past the loop's end into the first. Worked out again from the loop each time what is heard may have changed.
